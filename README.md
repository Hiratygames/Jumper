# 作品名：スライム君の冒険～スライム君と幻の花～
## ゲーム概要
スライムをジャンプさせ、どんどん上に進んでいくゲームです。<br>
上に行くのは大変ですが、落ちるのは一瞬。<br>
足を踏み外さないように気を付けながら慎重に次の足場に飛び乗っていく、緊張感のある操作が楽しめる2Dゲームです。<br>
## 開発期間
3か月（およそ60時間程度）
## 開発人数
1人
## 開発環境
Unity 6000.0.64f1
## 使用言語
C#
## 使用アセット
特になし
## 操作方法
PC:画面をクリックしたままスライドし画面に矢印が出た状態で離すと矢印の方向にスライムがジャンプします。<br>
スマートフォン:画面をタップしたままスワイプし画面に矢印が出た状態で離すと矢印の方向にスライムがジャンプします。<br>
引っ張りの大きさ（スワイプ量）に応じてジャンプの強さが変わり、引っ張りの向きでジャンプの方向が変わります。<br>
## 実装範囲
Unityのチュートリアルや公開されているプロジェクトなどは使用せず、一から自分で実装しています。<br>
TimelineやCinemachineなどの公式アセットは使用しましたが、サードパーティ製のアセットは使用していません。<br>
画像はCopilot、ChatGPTに作成してもらい、GIMPを用いて編集しました。<br>
BGM・SEはフリーのサイトでダウンロードしたものをプロジェクトに導入しました。<br>
## 工夫した点・特に見ていただきたいコード
### ・GameEventを用いたイベント駆動システム
Assets/Utility/GameEvents/Scripts/<br>
今作ではスクリプト間の結合を疎にする方法を模索してGameEventシステムを導入しました。<br>
イベント発火側も受け取り側もお互いを知る必要がないという点で便利で面白いデザインだと思います。<br>
良し悪しではありますが、Unityならではの方法を用いて実装できて非常に楽しいシステムでした。<br>
### ・GameEventによるチュートリアルシステム
Assets/Scripts/Game/Tutorial/<br>
チュートリアルシステムがGameEventを用いてプレイヤーの入力をイベントとして受け取り、表示を変更するシステムを構築しました。<br>
今作のチュートリアルは、プレイヤーの操作を止めずプレイの中で自然と表示される形で用意しています。<br>
操作方法がシンプルなので、プレイヤーが自由に操作して学んでいくということを意識してこの仕組みにしました。<br>
### ・Cinemachineを用いたカメラ制御
Assets/Scripts/Game/Camera/<br>
Assets/Scripts/Game/Stage/<br>
全体マップをステージ単位に分け、各ステージにカメラを配置してプレイヤーを追従します。<br>
ステージ切り替え時にカメラも切り替え、ステージの単位を保ちつつプレイヤーを追うように工夫しました。<br>
また、ステージ切り替え時に不要になったステージのRendererなどを切り、描画負荷軽減の工夫も取り入れました。<br>
### ・AudioMixerの導入
Assets/Scripts/Audio/<br>
Assets/Scripts/Game/BGMManager.cs<br>
AudioMixerを用いてステージに応じた音響効果に切り替える仕組みを作成しました。<br>
BGMは特定のステージの切り替え時にフェードを実行し、1つのAudioSourceで滑らかに切り替わるようにしています。<br>
また、これに合わせてサウンド設定UIも用意し、各種音量調整もできるように工夫しました。<br>
## 参考作品
### JumpKing
Getting Over ItやOnly Up!など、上に登っていくことを目的としたゲームは多々ありますが、
ジャンプのみを用いて登るというゲームシステムは、このゲームを参考にさせていただきました。<br>
マウス（タッチ）操作による無段階ジャンプ量制御、また方向まで制御するという差別化を行い、
スマートフォンでもPCでも遊べる操作で、より詳細な制御をできるように工夫しました。<br>
### モンスターストライク
引っ張って飛ばす、という遊び部分はこの作品の影響を受けていると思います。<br>
スライムのぷにぷにした質感と足のない体でジャンプして移動するというイメージから
引っ張ってはじく様に飛ばすというアクションの親和性を感じ、操作方法として導入しました。<br>
